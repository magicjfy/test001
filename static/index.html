输入银联登录凭证

浏览器登录 benefit.unionpayintl.com 后按 F12 打开 Console，执行下面代码，把结果粘贴到输入框：
JSON.stringify({token: sessionStorage.getItem('tokenUbrpH5'), deviceId: sessionStorage.getItem('deviceId')})
推送凭证到云端（可选，配合云端部署使用）

把本机的 token / deviceId 推一份到云端的程序实例，这样云端也能取码， /s/xxx 链接就长期有效、你关机也不断。token 过期时再推一次即可。

凭证从哪来 / 多久失效？

token 与 deviceId 存在浏览器 sessionStorage 里，换浏览器、清缓存或超时后就会失效，需要重新拷贝一次。 本工具把凭证存在本地 accounts.json，之后切换账号即可直接查，不用再开手机浏览器登录。
